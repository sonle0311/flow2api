# Instrument — Flow2API

Approved direction: A Instrument. User confirmation on2026-11-11: “Chọn A nhé, áp dụng thiết kế Instrument cho toàn bộ Flow2API giúp tôi, giữ đầy đủ các tính năng hiện tại.”

## World and use

An operating console for account readiness, image/video generation and API integration. Graphite work surfaces, precise Vietnamese typography and warm orange primary actions. The navigation is a narrow persistent tool rail on desktop and a bottom bar on mobile. The product's real account tables, request previews and media output are the visual material; no invented monitoring charts or sample accounts appear in production.

## Layout and preservation

Management retains all account, credential, quota, import/export, settings, CAPTCHA, browser, logging and integration controls. Studio retains every published/legacy model, reference image and video extension path, streaming progress, errors and outputs. Login retains JSON authentication and safe POST fallback. VPS desktop retains full-height interactive canvas and authenticated reconnect lifecycle. English, Vietnamese and Chinese remain complete.

Shared assets live in static/instrument.css and static/instrument-shell.js. Tailwind utility CSS is built locally and shipped as a static file; deployed Python/Docker operation does not need Node or an external CSS CDN. Existing IDs, event handlers and hiding mechanisms are behavior contracts. No backend generation/auth behavior is replaced by prototype code.
